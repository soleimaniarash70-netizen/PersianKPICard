قابلیت‌ها

ریال و تومان

تعیین واحد داده ورودی و تبدیل خودکار به واحد نمایشی.

نمایش فارسی

ارقام فارسی یا انگلیسی، RTL، عنوان و زیرعنوان قابل تنظیم.

مقیاس هوشمند

نمایش خودکار هزار، میلیون، میلیارد و تریلیون با اعشار دلخواه.

مقایسه دوره‌ای

Value و Comparison Value همراه درصد تغییر و نشانگر وضعیت.

ظاهر مستقل

رنگ، اندازه فونت و Bold/Normal برای اجزای اصلی کارت.

آماده داشبورد

پس‌زمینه، گردی گوشه‌ها و رنگ مثبت، منفی و خنثی.

روش استفاده

فایل PBIVIZ را از بخش Import a visual from a file وارد کنید.
Measure اصلی را در Value و مقدار مقایسه را در Comparison Value قرار دهید.
واحد پول، نوع ارقام، مقیاس و تعداد اعشار را انتخاب کنید.
رنگ‌ها، اندازه فونت، Bold/Normal و RTL را تنظیم کنید.
