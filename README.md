# Persian KPI Card

یک Custom Visual فارسی برای Power BI با پشتیبانی از:

- تبدیل ریال و تومان
- ارقام فارسی و انگلیسی
- مقیاس خودکار هزار، میلیون، میلیارد و تریلیون
- Value و Comparison Value
- درصد رشد یا افت
- RTL، رنگ، اندازه فونت و Bold/Normal مستقل

## Download

- [PersianKPICard v1.0.6](PersianKPICard-v1.0.6.pbiviz)
- [Power BI demo](PersianKPICard-Demo.pbix)
- [Excel demo source](PersianKPICard-Demo-Source.xlsx)

## Installation

در Power BI Desktop از پنل Visualizations گزینه **Import a visual from a file** را انتخاب و فایل PBIVIZ را وارد کنید.
